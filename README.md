# ArchiSense

**Evidence-Based Prioritization of Architectural Technical Debt in Java Systems**

ArchiSense is a research-oriented application for exploring architectural technical debt in Java software systems. It combines analysis results generated by the existing AsTdEA engine with a React frontend and Spring Boot backend.

## Current Implementation

The current application provides:

- Project and version information.
- Overview of available architectural analysis results.
- Architecture issue exploration.
- Issue search and detailed property inspection.
- Cross-version evolution metrics.
- Reports and CSV export.

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | React 19, Vite |
| Backend | Java 27, Spring Boot 4.1.2 |
| Build tool | Maven |
| CSV processing | Apache Commons CSV |
| Analysis engine | AsTdEA |
| Dataset | Apache Ant versions 1.9.4, 1.9.5 and 1.9.6 |

## Prerequisites

- JDK 27
- Node.js and npm
- Git

The backend includes Maven Wrapper scripts, so a separate Maven installation is not required to run it.

## Running the Backend

Open a terminal in the backend directory:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

Backend address:

```text
http://localhost:8080
```

## Running the Frontend

Open another terminal in the frontend directory:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

Frontend address:

```text
http://localhost:5173
```

## Verification

Backend tests:

```powershell
cd backend
.\mvnw.cmd test
```

Frontend lint:

The backend test, frontend lint and frontend production build have been successfully verified in the development environment.

## Data and Analysis Scope

The current application displays prepared AsTdEA results for Apache Ant versions 1.9.4, 1.9.5 and 1.9.6.

The frontend reads existing results through the backend. The current application does not automatically execute a new AsTdEA analysis when a user opens the dashboard.

All displayed analysis values originate from the prepared dataset and result files.

## Research Status

The current phase establishes the baseline application and integration of existing AsTdEA results. Additional research contributions and experimental improvements will be developed and evaluated separately.
